# CREATIVITY-CRAFT

This is a merge-crafting game, where players start with basic set of cards, each scored on some metrics; namely, music, art, design, and gameplay. The players must combine the elements to create newer, more interesting elements with unique properties. The goal of the game should be to create the element that represents the essence of creativity itself.
Merging items that have more "synergy" makes all their stats increase, while items that have less synergy get worse when they merge.
Players get synergy hints, but cannot see the actual synergy stats of their cards.
The game moves on infinitely, and when it ends the players are presented with a final score.
